# Belajar Python Dasar - Kelas Terbuka

Repositori ini berisi kumpulan kode program hasil proses belajar mandiri saya dalam mendalami dasar-dasar pemrograman menggunakan bahasa Python. Proyek ini dibangun untuk memperkuat pemahaman logika pemrograman dan struktur data dasar.

---

## 📌 Status Proyek: ✅ Selesai (Maintained)
Seluruh materi dasar dari kelas pengantar telah diselesaikan. Repositori ini akan terus dipertahankan dan diperbarui jika terdapat optimasi kode atau penambahan studi kasus baru.

## 🚀 Cakupan Materi & Fitur Kode
Di dalam repositori ini, terdapat implementasi praktis untuk beberapa konsep mendasar, antara lain:
* **Dasar Variabel & Tipe Data:** Pengenalan variabel, casting tipe data, dan penanganan input pengguna.
* **Operasi Matematika & Logika:** Operasi aritmatika, perhitungan sederhana, operasi komparasi, logika boolean, dan operator bitwise/assignment.
* **Manipulasi String:** Pengenalan dan manipulasi teks (string).

## 🛠️ Teknologi yang Digunakan

* **IDE/Text Editor:** Visual Studio Code
