💻 How to Run the Code Locally
Prerequisites
Ensure that you have Python 3 installed on your computer. You can verify this via the Terminal or Command Prompt (CMD):

```bash
python --version
```

Steps to Run the Code
Clone this repository to your local machine:

```bash
git clone [https://github.com/Alimurtadlo16/belajar-py-dasar-kelasTerbuka.git](https://github.com/Alimurtadlo16/belajar-py-dasar-kelasTerbuka.git)
```

Navigate to the directory of the material folder you wish to run (e.g., folder 01):

```bash
python main.py
```

(Adjust the .py file name according to the actual file inside the folder)
